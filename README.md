# QUICKnote

QUICKnote 是一款面向 Windows 的轻量桌面笔记工具，适合用来快速记录灵感、整理临时信息、保存截图文字、收纳图片与录音内容。

它的核心目标不是做“复杂的文档系统”，而是让你在尽量少打断当前工作的前提下，快速记下、分类、补充、回看和导出笔记。

## 核心作用

- 快速呼出悬浮记录窗，随手记下一段文字
- 将内容保存为新笔记，或追加到已有笔记
- 给笔记添加图片、录音、标签与收藏夹归类
- 支持隐藏收藏夹、置顶、自定义排序与批量整理
- 支持图片预览、图片备注、图片复制
- 支持备份、导出与本地数据持久化

## 适合的使用场景

- 临时灵感记录
- 工作中的待办碎片收集
- 网页/聊天/文档中的信息摘录
- 课程、会议、阅读过程中的速记
- 需要把图片、文字、录音放在同一条笔记里统一管理的场景


## 数据存储位置

应用数据默认保存在：

```text
文档/QuickNote/
├── data.json
├── config.json
└── assets/
```

其中：

- `data.json`：笔记、收藏夹等主要数据
- `config.json`：快捷键、排序方式、备份设置等配置
- `assets/`：图片、录音、缩略图等附件资源

## 快捷键

### 全局快捷键

- `Ctrl+Q`
  默认快速呼出 QUICKnote 悬浮记录窗  
  这个快捷键可在“设置 -> 快捷键设置”中自定义

### 笔记弹窗

- `Ctrl+S`
  保存当前笔记

- `Ctrl+Z`
  撤销正文编辑中的改动

- `Ctrl+Y`
  重做正文编辑中的改动

- `Ctrl+Shift+Z`
  重做正文编辑中的改动

- `Esc`
  关闭当前笔记弹窗

- `按住 Q + 鼠标滚轮`
  调整当前弹窗透明度

### 图片预览窗

- `← / →`
  切换上一张 / 下一张图片

- `Esc`
  关闭图片预览窗

- `鼠标滚轮`
  缩放图片

- `左键拖动`
  在图片放大后拖动查看

- `右键`
  打开图片菜单并复制当前图片

## 基本操作方法

### 1. 快速记一条内容

1. 按 `Ctrl+Q` 呼出悬浮记录窗
2. 直接输入文字
3. 按 `Ctrl+S` 保存

如果当前选择的是“新建笔记”，内容会保存为一条新笔记。  
如果当前选择的是已有笔记，内容会追加到该笔记末尾。

### 2. 创建完整笔记

1. 在主界面点击“新增笔记”
2. 输入标题和正文
3. 通过工具栏插入图片、录音或调整正文格式
4. 按 `Ctrl+S` 或点击保存按钮完成保存

### 3. 使用正文工具栏

笔记弹窗支持以下正文编辑操作：

- 字号放大
- 字号缩小
- 高亮
- 加粗
- 划线并置灰

其中划线、字号调整等操作支持撤销与重做。

### 4. 管理收藏夹

- 左侧栏可创建收藏夹
- 收藏夹支持拖动调整顺序
- 支持隐藏收藏夹
- 当收藏夹数量较多时会自动出现内部滚动，不影响底部设置按钮

### 5. 整理笔记

主界面支持：

- 按时间排序
- 自定义排序
- 置顶笔记
- 批量选择
- 全选
- 批量移动
- 批量删除
- 批量导出
- 合并多条笔记

### 6. 图片查看与备注

- 点击笔记中的图片可进入预览窗
- 可切换图片、缩放图片、拖动图片
- 可为图片填写备注
- 图片备注会自动保存
- 右键可直接复制图片


适合从截图、课件、文档或网页上快速提取文本。

### 7. 备份与恢复

在“设置 -> 存储与备份”中可以：

- 查看数据目录
- 打开数据文件夹
- 手动创建备份
- 导入备份
- 设置自动备份间隔（按天）

填写 `0` 表示关闭自动备份。

## 设置项说明

当前设置页主要包含：

- 全局快捷键设置
- 记住上次排序与收藏夹
- 快捷呼出时读取剪贴板
- 打开隐藏收藏夹
- 自动备份间隔
- 打开数据文件夹
- 创建备份
- 导入备份

## 导出能力

应用支持多种导出方式：

- 导出笔记内容
- 导出笔记图片
- 导出后的图片自动复制到剪贴板，方便直接发送

## 产品特点

- 本地优先：数据默认保存在本机，不依赖云端
- 轻量快速：更适合高频记录，而不是重型文档编辑
- 悬浮记录：尽量减少记录时的打断感
- 多模态笔记：文字、图片、录音可以放在同一条笔记中
- 适合整理：支持收藏夹、标签、置顶、批量操作、自定义排序
